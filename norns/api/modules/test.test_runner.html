Module test.test_runner

test/test_runner.lua finds and runs tests using LuaUnit.

run directly to discover and run all tests: lua test_runner.lua

or import as module for custom test workflows: local runner = require('test.test_runner') runner.run() -- run all tests runner.discover() -- find test files
